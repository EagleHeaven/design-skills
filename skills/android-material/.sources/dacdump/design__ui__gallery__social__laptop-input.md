# Keyboard and pointer on desktop
Source: https://developer.android.com/design/ui/gallery/social/laptop-input

<br />

Laptops provide precise and productive input controls with more interaction
states and keyboard shortcuts.

In media apps, the **Space** bar can control playback.

Keyboard shortcuts make creativity apps more efficient.

In social apps, pressing **Enter** sends messages faster.

Custom hover states make links more informative.
